# NEXT

NEXT is a calm support navigator for people who do not know what to do next. The first milestone gives people a welcoming place to share their situation before the product introduces AI guidance or persistence.

## Run locally

```bash
npm install
npm run dev
```

Then visit [http://localhost:3000](http://localhost:3000).

## Product principle

NEXT supports human agency. It will offer possible paths and a possible next step, rather than making decisions for someone.

See [HANDOFF.md](./HANDOFF.md) for the current milestone and the next implementation task.
